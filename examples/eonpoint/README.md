# EonPoint 案例源码

生成 `cases/eonpoint-yishiyikong/` 中全部图形的代码。**学工程写法，不复用造型和字形。**

| 文件 | 内容 |
|---|---|
| `src/ep.py` | 基础几何：描边 / 圆 / 填充三种图元、平移缩放、包围盒、渲染为 SVG |
| `src/latin.py` | 本案的几何英文字形（只有 E o n P i t 等用到的字母），按字高、线宽参数化 |
| `src/hanzi.py` | 本案的“亿触点”单线字形，点画为正圆 |
| `src/lockup.py` | 图形 + 英文 + 中文的组合排版（横式、单行、竖式） |
| `src/r4.py` | 最终方案：相切、句点、构造图、动态帧、色彩版本、图标，一键导出 |

## 运行

```bash
cd src
python3 r4.py        # 输出到 ../svg_r4/（运行后可删除）
```

只需要 Python 3 标准库。

## 值得学的写法

- **一个基准推出一切**：`LW`（线宽）与 `K_POINT`（点径比）等少数常量决定全部尺寸。
- **色彩版本与形状分离**：形状用角色名（`line`、`point`）标记，颜色在导出时按 `CW` 字典替换，一套形状导出所有色彩版本。
- **构造图与动态帧也由代码生成**：`cons_H1()`、`motion_H1()`。
- **对齐由计算得出**：`H3_standard()` 让中文句号的圆心与英文句点对齐在同一条竖线上。

## 不要做的事

不要把 `latin.py`、`hanzi.py` 的字形拿去给别的品牌用——每个品牌的字都要按它自己的构成语法重新画。
