# 测试简报：检验“风格一致，形式不同”

用途：每次修改风格四章后，让 AI 用本 skill 对下面的虚构品牌跑第 1–3 阶段（简报 → 概念 → 原型），检查两件事：
1. **气质是否到位**：通过 `style-dna.md` 的整体试金石与 `philosophy.md` 的十条自检。
2. **形式是否不同**：三个品牌的母题、造型语言彼此不同，也与 `cases/` 不同；没有出现点 + 圆 + 句号的套路。

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E1 | 守正律师事务所 / Shouzheng Law | 北京，商事诉讼与合规；客户是上市公司与跨国企业；想要“公正、冷静、可信”，不要天平和法槌 |
| E2 | 岚舍 / Lan House | 云南高山茶，线下茶空间 + 电商；客户是 25–40 岁城市白领；想要“安静、温润、有山气”，不要茶叶图形和书法字 |
| E3 | 芯恒半导体 / Corestead Semiconductor | 功率芯片设计公司，B2B；客户是汽车与能源企业；想要“精密、可靠、有远见”，不要电路纹和芯片图案 |

第二组（同一组连跑两三轮后换用）：

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E4 | 栖木童家 / Qimu Kids | 实木儿童家具，B2C，线上 + 门店；客户是 28–40 岁的父母；想要“安全、温暖、耐用”，不要卡通动物、彩虹、积木 |
| E5 | 澄听声学 / Chenting Acoustics | 建筑声学设计与工程，B2B；客户是剧院、学校和办公楼的业主与建筑师；想要“精准、安静、可靠”，不要声波纹、耳朵、音符 |
| E6 | 如初口腔 / Ruchu Dental | 连锁口腔诊所，B2C；客户是城市家庭；想要“干净、温和、专业”，不要牙齿图形、十字、微笑弧线 |


## 判定

| 检查 | 通过标准 |
|---|---|
| 母题来源 | 每个概念都写明来自名字或业务的哪里 |
| 不同 | 15 个概念（3 个品牌 × 5）中，以点 + 圆为主的不超过 2 个 |
| 跨品牌不撞形 | 三个品牌的推荐原型放在一起，一眼能分开；如果两个不同行业撞成同一个形，查 skill 的文字里是什么在当答案用 |
| 旋钮 | 每个品牌至少两个旋钮与 EonPoint 案例不同 |
| 黑白先行 | 第 3 阶段原型全部为黑白 |
| 流程 | 每阶段结束都等用户确认，并写入 decisions.md |
| 母题能成图形 | 15 个概念中，母题来自字形（汉字、字母、标点、数字）的每个品牌最多 1 个 |
| 速写 | 第 2 阶段每个概念都有黑白速写（用面和外形画），并写了图形感与辨识度自查 |
| 首先是图形 | 推荐原型遮住名字后，第一眼读成一个东西或画面，而不是字、字母、标点或图标；有完整的外形和面 |
| 辨识度（跑到第 3 阶段时） | 每个锁定概念的原型中至少 2 个走出图解、注明转译手法；剪影、反白、十字描述不像常见图标；签名细节在 32 px 仍看得见 |
| 风格 | 转译后的原型仍然轻、空、落定，答得出“东方在哪里”；没有为了辨识度变粗变满，也没有拆成几根线 |

测试记录写在 `records.md`。**跑测试的 AI 不要读 `records.md`**，以免被以前的结果影响。
