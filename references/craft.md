# 制作方法

这一章讲“怎么做出来”：构造、定制字、配色研究、渲染与导出。风格倾向（字的性格、颜色的取向）见各风格 skill 的 `style-dna.md`。

## 从图解到图形

母题第一次画出来，通常只是它的**图解**：照它在现实里的样子画出来（母题是字时，就是按常规字形写出来）。图解对题，却常常像一个已有的图标，让人看过就忘。标志还要再走一步，成为一个**只属于这个品牌的图形**：先是一个完整的图形，再让人记住。这一步发生在第 3 阶段，也是决定设计质量的关键一步。

概念本身就是一种手法时（例如概念本身就是一次图底反转），图解指把实和空都照常规样子画出来的那一版；转译要在这之上再走一步。

六种转译手法。每个原型都要写明用了哪一种（可以组合）；各风格偏爱哪几种，见各自的 `creative-methods.md`。

| 手法 | 做法 | 为什么有用 |
|---|---|---|
| 精确的关系 | 让两个元素之间有一个说得清、量得出的关系：相切、对齐、咬合、抵住、穿过、恰好容纳 | 关系是图标里少有的东西；一个精确的关系本身就是签名 |
| 极端的对比 | 把粗与细、大与小、实与空、长与短拉到极端 | 对比制造张力，让极少的元素也有力量 |
| 截取 | 只画母题的一部分，让看的人用想象补全 | 补全的过程让人参与，也让形不再像完整的通用图标 |
| 化为几何面 | 把母题归纳成几块简单的面（圆、方、弧形、三角的切分与拼合），不画细节 | 面让图形有分量和外形；归纳过的形既能认出母题，又不再是插图 |
| 图底反转 | 让空的部分成为主角，实的部分只是围出它的边 | 负形不容易与已有图标重合，也最耐看 |
| 一处偏差 | 在规则里留一处有意的偏离：缺口、错位、偏心、一次转折 | 完美的几何容易像图标；一处偏差让它像被人设计过 |

**画出来以后**：先过 `quality-gates.md` 的图形感和辨识度，再用本风格的试金石检查一次。三种情况都要换一种手法重做，而不是在原图上加装饰：
- 像一个已有的图标；
- 被拆成了几根线、几个笔画，读起来像一个字或符号；
- 辨识度上去了，风格却丢了（例如变得过重、过满）。

### 先想外形和面

构造一个图形时，先回答三件事：它的整体外形是什么，哪里是实，哪里是空。线可以用，但要围成形，或者成为形的边；几根互不相连的线和笔画，很容易读成字或符号。代码画图时，优先用填充的面（闭合路径）来构造图形，描边只用于确实是“线”的部分。

### 母题来自字形时

字形指汉字、字母、标点和数字的样子。名字的意思、读音和典故都是好的母题来源；字形不是默认来源。

- **默认不做字形标志**：标志首先是图形。每轮 5 个概念里，母题来自字形的最多 1 个。用户明确要字母标或以字为标时除外，记入 `decisions.md`。
- **什么算图解**：把这个字或字母按常规字形写出来——哪怕换了一种字体、加粗或几何化，仍然是图解。
- **什么算转译**：字被转成一个图形，第一眼读成一个东西或一个画面，认得这个字的人才多读出一层。中国银行的标志第一眼是一枚古钱，其次才是“中”。
- **判断**：过 `quality-gates.md` 的“第一眼读成什么”。第一眼仍然读成那个字、字母或标点，就还是字体设计。
- **与字标的关系**：标志里藏着品牌名的某个字时，字标里不要再并排出现这个字的另一种写法。
- **单个字母或数字**：先查它是否被用作政治、军事或宗教符号。

## 构造与参数化

- **一个基准，推出一切**：选一个基准尺寸（例如图形外径 D 或大写字高 H），所有尺寸写成它的比例。改一个数，全部文件跟着变。
- **代码生成**：图形、字、组合、色彩版本都由代码（`scripts/` 的工具或项目 `src/`）生成 SVG。不手工在设计软件里改，否则无法复现。
- **构造图**：把规则画出来（辅助圆、基线、比例标注），用于提案说明。规则只出现在构造图里，不出现在标志里。
- **视觉修正**：圆形和尖角要略超出基线（过冲）；横笔通常比竖笔略细；小尺寸版本要单独加粗或简化，不能只是缩小。

### 精修的顺序（第 4 阶段）

1. **定基准与规则**：选一个基准尺寸，写出所有比例的来源。
2. **曲线与交接**：放大到 400%，逐段检查弧线是否连续、交接是否干净、端头是否统一。
3. **视觉修正**：过冲、粗细补偿、交角的光学处理；在 100% 与 400% 下来回看。
4. **小尺寸版**：在 16–24 px 下重画一个加粗或简化的版本，与主标志并列。
5. **单色与反白**：纯黑、纯白、反白都要成立。
6. **构造图**：把规则画出来，作为提案的证据。
7. **转路径**：描边转为填充路径，合并重叠、清理多余节点，为交付做准备（见下文“渲染、审看与导出”）。

## 定制字：英文

- **从骨架开始**：先定字高、x 高度、笔画粗细、圆的比例，再逐个字母构造。只做名字里用到的字母。
- **不以任何现成字体为底稿**：可以参考某类字体的气质（几何、人文、衬线），但轮廓要自己画。
- **字距按面积，不按距离**：直笔与直笔之间留得多，圆与圆之间留得少；整体看起来间隔均匀。
- **一处设计**：整个字标只有一处与众不同的细节（与图形呼应的那一处），其余保持安静。处处有变化等于没有变化。
- **检查**：放大 400% 看接缝；缩小到 16 px 看可读性；单词整体看节奏。

## 定制字：中文

- **同样从骨架开始**：确定字身框、字面率、主笔画粗细；中文笔画多，视觉上比英文“黑”，通常要按字身折算减细，让中英文看上去一样重。
- **笔画数多的字要再减重**（例如“触”比“亿”笔画多得多），保持每个字的灰度一致。
- **点画、撇捺、折角的处理要与图形同源**：如果图形是正圆，点画可以是正圆；如果图形是折，折角可以呼应；不要另起一套语言。
- **结构**：注意中宫松紧、重心高低、左右部件的避让；方框类部件（口、日、田）要比外框略收，否则显得大。
- **检查**：与英文并排看重量是否一致；单字放大检查衔接；整体缩小看是否糊。
- 提醒用户：正式使用前，中文字标最好请字体设计师做一次光学精修。

## 图文同源的做法

1. 用一句话写下图形与字共同的规则（例如“弧都取同一个曲率，转角都是平切，字的笔画粗细从图形的边宽推出”）。
2. 同源在比例、几何、弧线张力和端头处理上，**不在结构上**：字可以向图形借一处细节，图形不要向字借结构，否则图形会变成一个字。
3. 至少让一个字母（或一个中文笔画）带上图形的那一处细节，让人看出它们是一家人。
4. 并排检查：遮住名字，图形还像这家公司的；遮住图形，字还像这个品牌的。

## 配色研究

1. **颜色从哪里来**：概念（母题本身的颜色）、材料（纸、墨、石、金属）、名字（字义里的颜色）、行业（反行业惯用色往往更有记忆点）。为每个候选颜色写一句理由。
2. **少**：先做无彩版本，再决定是否需要颜色、需要几种。
3. **成对给出**：每个图形配 2–3 套“字 + 色”组合，而不是颜色 × 字体的全排列。
4. **给颜色取名**：用物名或意象命名（例如“墨”“石青”），比编号更容易沟通，也更有品牌感。
5. **检查**：正文文字与底色对比度至少 4.5:1；深色底上的强调色要另行调整亮度；准备 HEX、RGB 和 CMYK 参考值，注明 CMYK 需打样校色。

## 渲染、审看与导出

- **渲染**：SVG → PNG。macOS 可用 `scripts/render.sh`（调用系统 Quick Look，无需安装）；其他平台用 `rsvg-convert` 或 Python 的 `cairosvg`。
- **审看图**：用 `scripts/sheet.py` 把多个 SVG 拼成一张对比图（可加标签），一次看全；用 `scripts/review.py` 生成图形感与辨识度的审看板。
- **导出清单**：每个组合 × 每个色彩版本的 SVG；常用尺寸的 PNG；App 图标（1024 px 圆角方形）与圆形头像。
- **描边转路径**：代码生成的 SVG 常用描边（stroke）。正式交付前要转成填充路径：在 Illustrator 中“对象 → 扩展”，或用 Inkscape 的“描边转路径”，或在代码中用几何库直接生成轮廓。
- **命名**：`<方案>-<组合>-<色彩版本>.svg`，例如 `A-stacked-reverse.svg`。
