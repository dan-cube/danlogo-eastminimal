# 风格基因

> 少而准，空而满，轻而有形；落定，有呼吸；字与图出自同一只手。

## 目录
- 九条基因
- 风格坐标：像谁，不像谁
- 旋钮：可以变的部分
- 模糊词在本风格里的意思
- 整体试金石

这一章描述**气质**，不描述具体的形状、颜色或工艺。每条基因都写明：是什么、为什么、试金石、常见误区。判断一个方案是否属于东方极简，用这九条和 `philosophy.md` 的十条自检，而不是看它有没有点、圆、某种颜色。

前提：本风格做的是**图形标志**。无论多少、多空、多轻，标志首先是一个有外形、有面的图形，而不是一个字或符号（见 `quality-gates.md`“怎么判断图形感”）。

**核心构成：实与空成对。** 本风格的标志由实和空**一起**构成：黑是一个形，白也是一个形，两者互相成全（第 2 条）。其他几条基因都围绕这一对关系展开。只满足其中一条往往会走到极端——只顾“有面、可辨认”，就成了一整块实心剪影；只顾“轻”，就成了一圈细框围着一片白。两种都不是本风格。

## 九条基因

### 1. 少
**是什么**：元素少到再删一个就不成立。每一个元素都有不可替代的职责。
**为什么**：少，意思才能集中；观看者的注意力只够承载一个想法（Dieter Rams：少，但更好）。
**试金石**：逐个遮住每个元素，问“没有它还成立吗”。如果成立，就删掉它。
**常见误区**：为了“丰富”“有层次”加元素；为了讲全业务，把多个意思拼在一起；把“少”做成几根线、几个笔画——少的是元素，不是形，剩下的仍要是一个完整的图形。

### 2. 空：实与空成对
**是什么**：空白是设计的一部分，不是剩下的地方。在标志的轮廓之内，白也要是一个看得见、说得出的形，和黑一样被设计；黑与白像一对，互相成全——拿掉黑，或者把白填上，意思都不成立。意思也不说满，给看的人留出位置。EonPoint 案例的名字“一实一空”，说的就是这件事。成对的安排不止一种——谁包住谁、是否咬合、白是否碰到外轮廓、各占多少，都可以变；一轮原型里至少要有两种不同的安排，不要都用同一种。
**为什么**：原研哉的“空”是一个容器，老子讲“无之用”——起作用的常常是空的那一部分（philosophy.md 第 4、5 条）。只有黑在说话，就是一个普通的剪影；只有白在说话，黑就退成了一圈框。
**试金石**：反白看，白的那一块本身是不是一个完整的形，能单独说出它是什么？把白填上，或者把黑减成一圈细线，意思是否都会垮？标志周围的空白挤掉一半，它是否明显变弱？
**常见误区**：一块黑上只留一道发丝缝或一个小缺口——白太弱；一圈细框围着一大片白——黑太弱；把“空”理解成“小”或“细”；把概念的每一层都画出来。

### 3. 轻
**是什么**：形是放下来的，不是压下来的。轻在气息，不在笔画粗细：一个饱满的面也可以轻——边缘安静，周围的白足够宽，形没有多出来的分量。墨多的时候，眼睛读到的应该是白：满的是墨，被看见的是空出来的那一部分。
**为什么**：东方极简的力量是收着的。重而满的形在大声说话，轻的形等人走近（philosophy.md 第 4、6 条）。
**试金石**：把它放在一大片白里，白是被它点亮了，还是被它占满了？墨多时，第一眼读到的是墨还是白？`review.py` 给出的墨色比例只作参考，不是标准。
**常见误区**：为了辨识度把形做粗做满；反过来，把“轻”做成几根细线——线一细，形就散了，变成字或符号，丢了图形感。

### 4. 准
**是什么**：形的精度极高，比例有内在规则，所有尺寸都能说出来源；规则藏在里面，不露在外面。
**为什么**：少的东西经不起含糊。元素越少，每一处的精度越会被看见。
**试金石**：每个比例都能说出由哪个基准推出；放大到 400% 检查接缝与弧线；视觉修正（过冲、粗细补偿）都做过。
**常见误区**：“差不多”的弧线；为了显得严谨而把网格、辅助线露在标志里；为了“记得住”把形做粗做满——准是精确，不是分量。

### 5. 落定
**是什么**：形处在“刚刚完成”的那一刻——落下、停住、闭合、到位。重心低而稳，像一口气刚刚呼完，像一句话刚刚说完。它的张力来自**动后之静**：看得出它曾经运动、选择过位置，而此刻安定了。
**为什么**：东方审美里的“静”不是没有力量，而是力量收住之后的从容。对企业而言，它传达可靠、笃定、已经交付。
**试金石**：能说出它“停”在哪里、为什么停在那里；稍微挪动关键元素，画面就失去平衡；没有为了“动感”而倾斜、旋转、飞散。
**和动态的关系**：母题可以与运动有关（轨迹、旋转、摆动），动态版本也可以动；但标志本身是运动结束、刚刚停下的那一帧。
**倾斜本身是意思时**：可以斜，但形要停在“斜着却稳住”的那一刻——重心落在支撑之内，看起来不是正在倒下。
**常见误区**：落定说的是一个时刻，不是一种固定的构图；把“静”做成呆板的居中对称；用斜线、速度线、爆炸放射制造“科技感”和“活力”。

### 6. 字为题款
**是什么**：字与图形的关系，像中国画与画上的题款——同一只手、同一种气息，但字退后一步：更轻、更疏、更安静，托住图形而不与它争。中英文像同一个人用同一支笔写成，字距疏朗、节奏均匀，没有装饰性的变化。
标志默认是一个图形，名字里的字交给字标去写；图形不做成字的变体（见 `craft.md`“母题来自字形时”）。
用户明确只要纯字标时，字退到“只剩骨架”，让那**唯一一处**与众不同的细节成为全部焦点。
**为什么**：东方极简的标志只讲一件事；如果字也在大声说话，就变成了两件事。
**试金石**：放在一起看，视线先落在图形（或那一处细节）上；单独看字，它也安静、好看、经得起细看；中英文并排，像一家人。
**常见误区**：字比图形还抢眼；中英文各用一套风格；为了“有设计感”给每个字母都加变化。

### 7. 同源
**是什么**：图形、英文、中文出自同一种气质和同一套比例——同样的几何、同样的弧线张力、同样的端头处理和粗细关系。字可以向图形借一处细节，让人一眼看出是一家人。
**为什么**：拼搭感来自“图是图、字是字”。同源让整个标志读起来是一个整体。
**试金石**：能用一句话说出图与字共同的规则；把图形和某个字母并排，看得出是同一个人设计的。
**常见误区**：图形用几何，字用现成字体；中文和英文的笔画粗细、端头处理、弧线张力不一致；反过来让图形向字借结构——图形一旦照着字的笔画来搭，就变成了一个字。

### 8. 色少有因
**是什么**：颜色少，每一种颜色都说得出理由——来自概念、材料、行业或名字本身。可以完全不用彩色；需要强调时，强调要少而准。
**为什么**：颜色是最响的声音。东方极简用颜色，就像说话时只重读一个字——只在需要的地方，一次就够。
**试金石**：去掉所有彩色，它还成立吗？每种颜色都能回答“为什么是它”吗？
**常见误区**：渐变、多色拼接；用“科技蓝”“活力橙”这类行业惯用色代替思考；把强调色撒在很多地方。

### 9. 可感
**是什么**：标志在不同材料、尺寸、感官和动态里都成立，并且在实物上更好：压印、刻、织、透光、在手里被摸到。
**为什么**：原研哉的感官设计——人对品牌的理解，来自屏幕之外的多种感受（philosophy.md 第 7 条）。
**试金石**：设想它被压在纸上、刻在金属上、绣在布上、做成一个动作——还成立吗？会不会更好？
**常见误区**：只在屏幕上成立的效果（细微渐变、发光、半透明叠加）；忽视小尺寸和单色。

## 风格坐标：像谁，不像谁

| 像（气质上） | 不像 |
|---|---|
| 老子的“无之用”、八大山人、枯山水、无印良品、原研哉、Dieter Rams 的“少而好” | 硅谷式渐变与发光、电路板和神经网络图案、拼贴组合图形、多色点阵、卡通圆润、奢侈品金色、祥云回纹等装饰性的“中国风”、“日式”符号堆砌；字体的变体，以及用字母、标点、笔画搭出来的标记 |

“东方”体现在**观念**（空、白、轻、落定、含蓄）上，而不是传统纹样上。一个完全几何化、没有任何传统元素的标志，也可以非常东方。

**Dieter Rams 取什么**：只取“少，但更好”和诚实的思想。工业产品那种冷静、完美、对称的几何外观，不在本风格里——一个形如果只是“精确的几何物件”，它更接近瑞士和包豪斯，而不是东方。

**显性引用与“堆砌”的界线**：可以引用一个传统元素（一种传统的媒介、做法或轮廓），条件是只引用一个，并且经过转译——几何化、简化或改变用途，让人先看到新意思，再认出出处。两个以上传统元素叠加，或把纹样、器物原样照搬，就是堆砌。

## 旋钮：可以变的部分

风格靠上面九条守住；下面这些“旋钮”每个项目都应该重新拧。**新项目的最终方案至少要有两个旋钮的取值与 `cases/index.md` 里所有案例明显不同**，除非用户明确要求。这是对整个项目的要求，不是对每张概念卡。

| 旋钮 | 范围 | EonPoint 案例的取值（只作对照） |
|---|---|---|
| 造型语言 | 面、块、弧、折、缝、负形、剪影、点、线、笔触 | 线、圆、点 |
| 力度 | 发丝般轻 ←→ 厚重如印（重的一端也要“轻”：读到的是白，见第 3 条） | 偏轻 |
| 温度 | 冷静几何 ←→ 温润手作 | 中性偏冷 |
| 色彩 | 无彩 ←→ 单一强调 ←→ 双色 | 单一强调 |
| 东方程度 | 只在气质里（含蓄） ←→ 显性引用（借用一种传统的媒介或做法） | 含蓄 |
| 字的性格 | 几何 ←→ 书写 ←→ 衬线；大写 ←→ 小写 ←→ 中文主导 | 几何，大写 / 首字母大写 |
| 材料想象 | 纸、石、木、布、金属、光、水、声音 | 纸 |
| 构图 | 居中 ←→ 偏置；横 ←→ 竖 ←→ 方 | 居中，竖与横 |

## 模糊词在本风格里的意思

用户的反馈常常是模糊词。先按下表翻译成本风格里可以观察的做法，再动手（共用的 `feedback-playbook.md` 会指到这里）。同一个词在别的风格里意思不同，不要套用。

| 用户说 | 在东方极简里是 |
|---|---|
| 高级、有质感 | 元素更少；一个更精确的关系；实与空成对；一处强调色，而不是更多颜色或效果 |
| 简约 | 再删一个元素就不成立；空白被设计，而不是剩下来的 |
| 有张力 | 两个元素之间极端的对比（大小、虚实、远近）；一处有意的偏差 |
| 有呼吸 | 白是一个被设计的形；挤掉周围一半空白，标志会明显变弱 |
| 稳重、可信 | 重心低；关键元素停在说得出理由的位置 |
| 东方感 | 留白在说话；不对称而平衡；形里有一个刚结束的动作；意思留一半——不靠毛笔、印章、祥云这类符号 |
| 年轻、有活力 | 一处意外的关系，或更明亮的一处强调色；不加元素、不加效果 |
| 温暖 | 物名色；柔和的弧；看得见的手的痕迹（一处偏差） |
| 科技感 | 精度和一个准确的关系；不靠光效、渐变、电路与网格 |

## 整体试金石

交付前，用这十一个问题整体看一遍。第 3 阶段只有黑白图形，判断第 1–9 问；第 10、11 问到第 5 阶段有了字和色再判断。

1. **首先是图形**：遮住名字，它第一眼是一个东西或一个画面，而不是一个字、字母、标点或图标吗？
2. **一句话**：能用一句话说出它的新认识吗？
3. **删除**：再删一个元素，还成立吗？成立就删。
4. **落定**：它停在一个说得出理由的位置上吗？
5. **轻**：放在一大片白里，白被它点亮了，还是被它占满了？
6. **实与空成对**：反白看，白的那一块本身是不是一个形？把白填上、或把黑减成一圈细线，意思都会垮吗？
7. **东方在哪里**：只看形、不听故事，回答四问，至少三问是“是”：
   - 留白在说话吗？去掉它，意思是否少了一半？
   - 它不对称而平衡吗？完全对称、居中、四平八稳的几何物件，更像瑞士式。
   - 形里有没有一个刚刚结束的动作——落下、收住、合上、放下、停稳——而不是一件静止的完美物件？静物也有“刚被放下”的那一刻。
   - 意思有没有留一半给看的人补？一眼就说尽的，不够东方。
8. **记得住，但没有变重**：剪影、反白、十字描述都不像一个常见图标——而且力量来自外形、关系与对比，不是靠加粗加满换来的。克制要克制到“少而有力”，不能克制到“少而无名”，也不能为了有名而丢掉轻与空。
9. **不重复**：和 `cases/` 里的案例放在一起，一眼能分开吗？
10. **同源**：图形和字像同一个人做的吗？
11. **经久**：五年后、十年后还会好看吗？
