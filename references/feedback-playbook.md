# 反馈对照表：反馈 → 诊断 → 动作

用户的反馈常常很短。先对照这张表判断真正的问题，再动手。

具体项目的反馈原话记录在各 skill 的 `cases/` 里。某条反馈规律如果适用于整个 danlogo 系列，在第 9 阶段建议加入 `danlogo-standard` 的这张表，再同步到各 skill。

| 用户可能说 | 通常的问题 | 动作 |
|---|---|---|
| 啰嗦、繁琐、越改越丑 | 元素太多、层级太多、颜色太多；在原图上不断加东西 | 退回上一阶段，回到一个母题、一个想法；做删除测试；不要在原图上继续加 |
| 密集恐惧、太密 | 重复的小元素过多、间距太小 | 减少数量（往往减到个位数）、拉大间距，或换母题 |
| 不成熟、AI 味、拼搭感 | 图形和字两套语言；用现成字体；元素来源不一 | 定一套构成语法，让图形与字同源；字从零绘制；统一线宽或粗细关系 |
| 不像 logo、像字体、像个符号 | 母题来自字形，或形被拆成几根线、几个笔画；没有外形和面 | 回到第 2 阶段，换一个能长成图形的母题（事物、现象、动作、空间）；用面和外形来画；过 `quality-gates.md` 的“图形感” |
| 辨识度不强、像个图标、记不住 | 停在母题的图解，没有签名细节，或签名太小 | 用 `craft.md` 的六种转译手法重做（关系、对比、截取、化为几何面、图底反转、一处偏差），让签名成为形的主体；不要靠加元素解决 |
| 闷、一块黑、像剪影 | 只有实在说话，轮廓里的空没有被设计；签名只是一道缝 | 让空成为一个看得见、说得出的形，回到本风格的核心构成关系（见 `style-dna.md`）；不要只加一道缝 |
| 太重、太硬、不够轻 | 为了辨识度或小尺寸，把主标志做粗做满 | 主标志回到本风格的力度，辨识度从外形、关系和对比里找；另做一个加粗的小尺寸版 |
| 不够高级、不够艺术 | 太直白（行业俗套、字面图解）；装饰多；颜色俗 | 越过第一反应，换一个更日常、更意外的母题；减色；增加留白 |
| 太规整、死板 | 网格和对称暴露在外；缺少张力 | 让规则藏在里面；引入一处不对称、一个缺口或偏移，让它落定而有势 |
| 太复杂（说的是字） | 字的变化太多，每个字母都在“设计” | 字退到只剩骨架，只保留与图形呼应的一处细节 |
| 太幼稚、太亮 | 饱和度过高、颜色过多、圆润过头 | 降饱和、减色、用物名色；收紧圆角或弧度 |
| 都不满意 | 方向错了，不是细节问题 | 不要微调；回到第 2 阶段换母题，或回到第 1 阶段重新确认品牌本质 |
| 太具体、太死板（说的是规则或方案） | 规则落到了具体颜色、形状或工艺上 | 把具体项移到案例里，规则只保留原则、理由和自检问题 |
| 喜欢某个思路 | 抓住了用户的审美 | 记录原话与原因；在后续轮次延续这个思路，但换形式；第 9 阶段沉淀进 skill |
