## 原则：让“空”在更大的尺度上继续成立

东方极简的标志靠**实与空成对**成立（`style-dna.md`）。延展不是把标志贴到各处，而是让这对关系在一页版面、一套图标、一段动态、一个空间里继续成立：版面里的空白和标志里的空一样被设计，体系里只有一处强调，每一段动作最后都落定。

最容易走样的地方有三处：
- **把空做成“没内容”**：空白多，却没有一个让人停下来的形或关系，页面只是显得未完成。
- **默认模板混进来**：渐变按钮、阴影卡片、堆满的素材图、通用图标——每一样单独看都“正常”，放在一起就不再是这个风格。
- **动态加花**：弹跳、闪光、旋转，把一个安静的标志变成了广告。

## 1 体系

| 项 | 东方极简怎么做 | 为什么 |
|---|---|---|
| 辅助图形 | 从标志的**核心构成关系**里取一个关系，变成版式规则：一条与标志同线宽的细线、一个总停在同一位置的强调、一种固定的留白比例。不把标志缩小平铺成花纹。一页里通常只出现一次 | 辅助图形是标志的“回声”，不是第二个主角；平铺的花纹会把“少”变成“满” |
| 版式与网格 | 空白多于内容；不对称而平衡——内容偏向一侧，另一侧留给一个形或一片空；严格对齐，靠对齐和间距产生秩序，少用框和色块 | 版面的空和标志的空是同一种空；秩序藏在对齐里，不暴露成线框 |
| 字体系统 | 辅助字体与定制字同一种声音：轻字重、几何或人文的骨架。层级靠字号与字距拉开，少用加粗和颜色；题名可以疏朗，正文安静 | 字为题款：字托住图形，不和它抢；靠分量对比会破坏“轻” |
| 色彩比例 | 底色占绝大部分，墨承担结构，强调色只在一处、面积很小。整片强调色作底只用在少数几个需要仪式感的地方（封面、某一个版本） | 色少有因：一处强调才有分量；处处都有就等于没有 |
| 图片与插画 | 少用。用时选单一主体、大面积留白、自然光、看得见材料质感的摄影；不用概念插画、3D 渲染和“科技感”素材图 | 图片也要“让物性说话”；素材图会把整套设计拉回行业默认 |
| 图标 | 与标志同一线宽、同一基准；以线为主，必要时一处实心；不加阴影和渐变 | 图标是标志的家族，要像同一只手画的 |
| 动态的性格 | 慢、少、落定。一个动作只说一件事（出现、思考、完成），终点帧就是标志；缓入缓出，停顿比运动更重要；不弹跳、不闪光、不做无意义的循环 | 有生命的形：像一次呼吸；落定是本风格的签名 |

## 2 场景

| 项 | 东方极简怎么做 |
|---|---|
| 最能证明本风格的场景 | 近看的工艺与触感（名片、纸品）；远看的空间（大片墙面里一个不大的组合）；小尺寸的界面状态（图标、加载与完成）。优先做这几类，它们最能显出“少而准”和“可感” |
| 材料与工艺 | 偏爱能被触摸的材料性格：纸、木、石、布、金属的本色。工艺用来让人“感到”而不是炫技——压印、一处烫印、材料本色，往往比满版印刷更合适 |
| 场景示意的气质 | 统一的暖灰纸色底、柔和的平光、正面或很小的角度；画面里只放标志和必要的元素，道具越少越好。示意图本身也是本风格的一页 |

## 3 提案

| 项 | 东方极简怎么做 |
|---|---|
| 版面 | 一页一个想法，空白多于内容；标题短，图与字各自有呼吸，不挤在一起 |
| 字与色 | 延续标志的字；大部分页面是纸色底，封面或一两个关键转折页可以用整片强调色或墨色作底 |
| 叙事的语气 | 安静、肯定、少形容词；先讲“重新认识”，再给出一个形。像在讲一个发现，不像推销 |
| 页面节奏 | 满页（构造图、场景、体系）与空页（一句话、一个形）交替；关键页之前，可以先放一页只有一句话的停顿 |
| 封面 | 标志或字标加一句话，大面积底色或留白；看封面就感到安静 |
| 证据的呈现 | 构造图单独成页，线细、标注少、单色——它是提案里最有说服力的一页；审看板与测试整齐地放在后面 |

## 4 规范手册

沿用提案的版面规则：每页一条规范，图例多于文字，尺寸用基准单位标注。错误用法同样安静地陈列，一页一种，不用红叉铺满。

## 延展试金石

交付第 6–8 阶段前，用这几个问题整体看一遍：

1. 遮住标志，看任意一页提案、一个场景、一段动态：还认得出是这个品牌、这个风格吗？
2. 辅助图形能说出它从核心构成关系的哪一部分长出来吗？一页里是不是只出现了一次？
3. 这一页的空白是被设计的吗？把它挤掉一半，这一页会不会明显变弱？
4. 强调色在这一页是不是只在一处？
5. 每一段动态最后都落定了吗？停顿比运动更重要吗？
6. 和标志并排看，有没有哪一样东西的审美不属于本风格（默认模板、素材图、花哨的动效）？

## 案例：EonPoint 怎么延展

只借方法，不借形式：这里的线、圆、点、胭脂红、盲压是 EonPoint 的答案，不是本风格的规定。

| 环节 | 案例里怎么做 | 体现了哪条原则 |
|---|---|---|
| 辅助图形 | 与标志同线宽的细线做版面的上下分隔；没有把圆和点平铺成花纹 | 从“一根线宽贯穿”长出来；辅助图形不抢主角 |
| 版式 | 官网首屏文字靠左，大尺寸的标志放在右侧，中间是大片纸色 | 不对称而平衡；空也被设计 |
| 字 | 字标大写、宽字距、轻字重；中文按字身折算到同一线宽 | 字为题款；同源 |
| 色彩 | 纸色为底、墨为结构，胭脂只在点上；封面和“句点”版用整片胭脂作底 | 色少有因：一处强调，少数地方用整片色制造仪式感 |
| 动态 | 点沿圆周运行表示“思考中”，停在最低处表示“完成”；终点帧就是标志 | 落定；有生命的形；标志同时是产品里的状态 |
| 场景 | 名片正面盲压、背面横式组合；形象墙在大片墙面里只放一个小组合；纸色与墨色两种手提袋 | 可感；空；工艺让人感到而不是炫技 |
| 提案 | 先讲“一实一空”的认识，再给相切与句点两个方案；构造图单独成页 | 先讲认识再讲形；构造图是证据 |
