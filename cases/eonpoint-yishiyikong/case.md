## 简报

- **品牌**：EonPoint 亿触点（AI 企业服务，B2B）
- **业务**：面向企业的 AI 服务——Agent 研发与企业软件服务（B2B）。
- **起点**：用户带来一张 AI 生成的参考图（左侧一个大圆点、右上 2×4 小点阵、衬线体 EonPoint、拉宽字距的“亿触点”，酒红色）。认可“从一个点到多个点”的概念，但觉得“有密集恐惧”“不够成熟，符号化不强，像 AI 拼搭”。
- **期望**：硅谷 AI 大厂的气质、成熟、有艺术感。

## 过程：四轮与用户反馈

| 轮次 | 做了什么 | 用户反馈 | 教训 |
|---|---|---|---|
| 1 | 裂变（1→2→4 分级点阵）、星芒（1+8 点 ✦）、点动成线（e 带红点） | “深化反而更啰嗦繁琐……不要越变越复杂，反而越变越丑” | 在概念上加层级、加颜色，只会更像 AI 拼搭 |
| 2 | 回到简单：一个大点 + 4 / 6 / 8 个小点；e 带红点的三种字重 | “好像都不满意” | 只把原稿排整齐不等于高级；方向本身需要换 |
| 3 | 转向原研哉的思路：相切（细圆环 + 内切的点）、盲点（盲文点位 + 浮雕）、句点（EonPoint. + 亿触点。） | 保留相切与句点，要求“图文呼应、同一套设计理念” | 从“画点”转到“重新认识点”，方向才对 |
| 4 | 两案统一为“一实一空”：英文句点实、中文句号空；一根线宽贯穿图形与中英文；完整提案 | “很喜欢这套设计思路”，并要求沉淀为 skill | 思想统一后，两个方案自然成为一个体系 |

各轮的汇总图见 `images/round1-rejected.png`、`images/round2-rejected.png`、`images/round3-hara.png`。

用户在沉淀 skill 时补充的关键反馈：“只有一处朱红”这类规则“过于具体，会影响创新能力”——规则必须停在原则层，具体做法只留在案例里。

## 最终方案

**核心概念「一实一空」**：英文的句点是实心的点——被触及的那一个，触点；中文的句号是空心的圈——能容纳亿万个点的容器，亿。

- **方案一 · 相切（合）**：一个细圆环，一颗实心点从内部与圆环相切于正下方。两个圆只在一点相接，这一点就是“触点”。字标 EONPOINT 中 POINT 的 O 与标志同圆、同线、同位置的点。动态：点沿圆周运行表示“思考中”，停在最低处表示“完成”。
  `images/H1-stacked-color.svg`、`images/H1-construction.svg`、`images/H1-logotype-cn-color.svg`
- **方案二 · 句点（分）**：EonPoint. 以实心红色句点结尾，亿触点。以空心红色句号结尾；中文行右对齐，句号正落在句点正下方的同一条竖线上。动态：AI 回答时闪烁的光标写完后缩成句点。
  `images/H3-standard-color.svg`、`images/H3-construction.svg`、`images/H3-symbol-color.svg`

构成语言：一根线、一个圆、一个点；线宽为大写字高的 6.2%，图形、英文、中文共用（中文按字身折算约 0.68 倍）。色彩：和纸白、墨、胭脂（深色底换朱）。

## 反向拆解：思想、基因、方法分别落在哪里

| 本风格的要求 | 在本案中的体现 |
|---|---|
| 原研哉·再设计 / 未知化 | 句号是人人每天都在用、却从没注意过的符号 |
| 原研哉·空 | 空心的句号是容器，容纳“亿”；意思不说满 |
| 原研哉·让物性说话 | 两圆内切只有一个公共点——“触点”是几何事实，不是附加说明 |
| 原研哉·有生命的形 | 点在圆中运行与落定，像一次呼吸 |
| 基因·少 | 方案一只有两个元素；方案二只有文字和两个标点 |
| 基因·落定 | 点停在圆的最低处、句子的末尾——动后之静 |
| 基因·字为题款 | 字重轻、字距疏，托住图形；纯字标时只保留句点一处焦点 |
| 基因·同源 | 字母 O 就是标志；句号的圈就是一笔中文笔画 |
| 基因·可感 | 盲压圆环 + 烫印红点的名片构想 |
| 方法·双语之间 | `.` 与 `。` 的一实一空 |
| 方法·一对矛盾 | 实与空；两个方案分别讲“合”与“分” |
| 方法·越过第一反应 | “点”的第一反应是画圆点（第 1、2 轮），越过后才找到“句号” |

## 旋钮取值（新项目至少两项要明显不同）

造型语言：线、圆、点｜力度：偏轻｜温度：中性偏冷｜色彩：单一强调｜东方程度：含蓄｜字的性格：几何，大写 / 首字母大写｜材料想象：纸｜构图：居中

## 可以借的方法

- 从名字里的一个字（“点”）出发，去找这个字在日常中最被忽略的形态（标点）。
- 在中英文之间找“同一样东西、不同长相”，让双语标志成为一个整体。
- 让概念落在一个可以画、可以量的事实上，构造图本身就是提案里最有说服力的一页。
- 让标志同时是产品里的状态（加载 / 完成），把品牌延伸进界面。

## 查重结论（2026-10 初步排查）

- 方案一的图形与方案二的字标未见与知名品牌雷同；“字标后加句点”是常见手法（Tumblr、Fiverr 等），难以独占。
- 方案二的“E.”App 图标属于常见的“字母 + 点”结构，容易与已有图标相近，建议更换。
- 正式的商标检索由品牌方另行进行；本案只记录设计层面的初步排查。
